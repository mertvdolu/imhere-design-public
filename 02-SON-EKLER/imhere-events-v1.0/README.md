# Events V1 · Cream & Ink v2.3

[Interactive preview](ONIZLEME.html) · [Handoff](HANDOFF.md) · [Specification](SPEC.md) · [36-state matrix](SCREEN-STATE-MATRIX.md) · [Proposed EN/TR copy](COPY-REVIEW.md)

An additive mobile design package for the approved limited Events V1 development scope. Event content is explicitly fictional preview data. No application/backend code or production release is included.

- `catalog.json` / `catalog.js`: deterministic screens and variants.
- `tokens.components.json`: common token references plus Events-only measurements.
- `l10n/*`: **52 proposed keys per language, NOT approved localization**.
- `assets/*.svg`: original abstract fixture art; not production event content or store assets.
- `source/FOUNDER-BRIEF.txt`: current scope authority.
- `evidence/validation.json`: checks performed and native limits.
- `MANIFEST.json`: local file sizes and SHA-256; excludes itself.

For an offline preview, open ONIZLEME.html with its sibling files intact. No dependencies, build step or network asset is required. For browser tools, serve the repository locally and open the HTTP preview. Preview selectors are reviewer controls, not user-facing app settings.
