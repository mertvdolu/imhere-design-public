# E-posta logo varlıkları

Kaynak: mevcut `imhere-mark-icon-weight.svg`. Yeni logo tasarlanmadı. Geometri aynı;144×92 tuvalin içine0.34 px düşey boşluk eklendi.

- `logo-on-light.svg` / `logo-on-light@2x.png`: Ink #14161A, saydam; krem zemin.
- `logo-on-dark.svg` / `logo-on-dark@2x.png`: Cream #F4F1E9, saydam; Ink zemin. Bu e-posta brifi kapsamındaki koyu sürümdür; notification maskesi kaynak değildir.
- PNG144×92, HTML görüntü72×46; alt metin `I'M HERE`.
- Wordmark HTML metnidir; varlıklarda yazı yok. Logo gölgesiz, düz, oranı korunmuş. Minimum çevre boşluğu12 px.
- SVG kaynak, PNG istemci varlığı. Son içerik hostu/CID Code tarafından belirlenir. Görsellerin tamamının byte/hash listesi MANIFEST'tedir.
